This time build an application with an interactive menu to test your functions

  1. Create a file called Units.py

  2. Create a user defined method called mi_to_km(mi) that accepts a floating point number as a parameter, converts it to kilometers using the same formula you used in lab 1, and returns the result

  3. Write the menu application, this code is given to you, and test your mi_to_km() function.

     

  4. Add the remaining methods to the Units.py module, for each of the remaining menu items.

    You can use the formulas you were given in earlier labs:

    • miles = kilometers * miles_per_kilometer
    • kilometers = miles / miles_per_kilometer
    • pounds = kilograms * pounds_per_kilogram
    • kilograms = pounds / pounds_per_kilogram
  5. Be sure to test your code!
