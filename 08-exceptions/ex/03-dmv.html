Exercise 3

Vehicle Lookup

For this exercise you're given two (CSV) data files, one contains a list of vehicles, and the other is the registration information including the license plate number assigned to each vehicle.

Create a Python file named vehicle_lookup.py and start with the code provided. Some of the code is missing.

Write the necessary functions to read the two data files into dictionaries, and then run the test to display the search results.

Do not hard-code any values. Your program may be tested with a different set of test data and input files.

 

data files

  • cars.csv
  • registration.csv
