Exercise 4

Dice Game (Revisited)

In this exercise, you will make the following modifications to the dice game from exercise 2:

  • Prompt the user for the number of rounds they want to play.
  • Code a loop to play the user entered number of rounds.
  • Keep score for the player and computer.
  • At the end, display who won the game after all rounds have been played (player, computer or tie).

You must complete exercise 2 before starting this.

Start with a copy of the DiceGameExercise2.py as DiceGameExercise4.py.
