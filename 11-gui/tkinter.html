Introduction to tkinter

tkinter is Python’s standard library for creating graphical user interfaces (GUIs). It allows you to build programs with windows, buttons, labels, and text fields instead of relying only on text input and output in the console.

tkinter programs are event-driven. This means your program waits for the user to do something—such as clicking a button—and then responds by running the appropriate code.

In this handout, you will build a simple tkinter application step by step to see how GUI programs are structured.

The Basic Structure of a tkinter Program

Most tkinter programs follow the same basic pattern:

  1. Import the tkinter module
  2. Create the main application window
  3. Create widgets (labels, buttons, etc.)
  4. Place widgets in the window
  5. Start the event loop

You will see each of these steps as you build your first app.

Step 1: Import tkinter

Start by importing the tkinter library. The common convention is to import it with the name tk. 

import tkinter as tk

This allows you to access tkinter classes and functions using the tk. prefix.

Step 2: Create the Main Window

Every tkinter application needs a main window. This window acts as the container for all other GUI elements. 

root = tk.Tk()
root.title("My First tkinter App")

The Tk() object represents the main application window. Setting a title helps users identify your program.

Step 3: Create a Label Widget

A Label is a widget that displays text in the window. 

label = tk.Label(root, text="Hello, tkinter!")

The first argument (root) specifies the parent window. The text argument defines what the label will display.

Step 4: Place the Widget in the Window

Creating a widget does not automatically display it. You must tell tkinter where to place it. One simple layout method is pack(). 

label.pack()

The pack() method automatically positions the widget in the window.

Step 5: Add a Button and an Event Handler

Buttons are interactive widgets. When a button is clicked, it triggers an event. The code that runs in response is called an event handler.

First, define a function that will run when the button is clicked. 

def on_button_click():
    label.config(text="Button clicked!")

Next, create the button and connect it to the function using the command option. 

button = tk.Button(root, text="Click Me", command=on_button_click)
button.pack()

Step 6: Start the Event Loop

The final step is to start the tkinter event loop. This tells Python to wait for events such as button clicks and window actions. 

root.mainloop()

Once mainloop() is running, your program responds to user actions until the window is closed.

Complete Example Program

Below is the complete program with all steps combined. 

import tkinter as tk

def on_button_click():
    label.config(text="Button clicked!")

root = tk.Tk()
root.title("My First tkinter App")

label = tk.Label(root, text="Hello, tkinter!")
label.pack()

button = tk.Button(root, text="Click Me", command=on_button_click)
button.pack()

root.mainloop()

What You Learned

  • tkinter is Python’s standard GUI library
  • GUI programs are event-driven
  • Widgets such as labels and buttons create the user interface
  • Event handlers respond to user actions
  • The event loop keeps the application running
