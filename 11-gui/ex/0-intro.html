Introduction

In this lab, explore writing event-driven graphical user interface (GUI) using Python's tkinter and matplotlib modules.

Instead of running from top to bottom like a traditional console program, event-driven code waits for the user to take an action (such as clicking a button). When that action occurs, a specific function is executed.

    Objectives:
  • Understand the concept of event-driven programming
  • Create a simple GUI application using tkinter
  • Handle user interactions with event handlers

What Does “Event-Driven” Mean?

In an event-driven program, the flow of execution is controlled by events such as:

  • Button clicks
  • Keyboard input
  • Mouse movement

Unlike console programs that follow a fixed sequence of statements, a GUI program:

  • Displays a window
  • Waits for the user to act
  • Responds by running an event handler (also called a callback function)
