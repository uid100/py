Event‑Driven Programming with Tkinter

MPG Calculator GUI

Program Overview

Use Python's tkinter module to create a simple graphical user interface (GUI) for calculating miles per gallon (MPG) and fuel costs.

Earlier, you wrote a console program to calculate MPG and fuel costs. This GUI version provides a more user-friendly way to input data and see results.

  • Miles per Gallon (MPG)
  • Total fuel cost
  • Cost per mile

All calculations are triggered by the user clicking the Calculate MPG button.

High-Level Program Structure

This program follows a common GUI pattern:

  1. Import the GUI library
  2. Define event handler functions
  3. Create the main window
  4. Add widgets (labels, entries, buttons)
  5. Start the event loop

Code Explanation

Importing Tkinter

                from tkinter import *

This line imports everything from the tkinter module so we can easily use widgets like Label, Entry, Button, and Tk.

Tkinter is Python's standard GUI library and is included with Python installations.

Event Handler Functions

The Calculate Button Handler

            def calculate_mpg():

This function is an event handler. It is not executed immediately. Instead, it runs only when the user clicks the Calculate MPG button.

Getting User Input

            miles = float(miles_entry.get())
            gallons = float(gallons_entry.get())

The .get() method retrieves text from an Entry widget. Because Entry widgets store text, the values must be converted to float before performing calculations.

Performing Calculations

            mpg = miles / gallons
            cost_per_gallon = float(cost_entry.get())
            total_cost = gallons * cost_per_gallon
            cost_per_mile = total_cost / miles

Each calculation uses basic arithmetic and meaningful variable names to improve readability and maintainability.

Displaying Results

            mpg_label.config(text=f"Miles per Gallon: {mpg:.2f}")

The .config() method changes the text displayed in a Label. Using formatted strings (f-strings) ensures results appear with exactly two decimal places.

Exit Button Handler

            def exit_program():
                frm.destroy()

This function is called when the Exit button is clicked. It closes the application window and ends the program.

Creating the Main Window

            frm = Tk()
            frm.title("MPG Calculator")
            frm.geometry("450x200")

This creates the main application window.

  • Tk() creates the window
  • .title() sets the window title
  • .geometry() controls the window size

Widgets: Labels and Entry Fields

Widgets are the building blocks of a GUI. This program uses:

  • Labels to display text
  • Entry widgets for user input
            miles_label = Label(frm, text="Miles Driven:")
            miles_entry = Entry(frm, width=8)

Each widget is attached to the main window (frm).

Layout Management with Grid

            miles_label.grid(row=0, column=0)
            miles_entry.grid(row=0, column=1)

The grid() layout manager organizes widgets into rows and columns, similar to a table.

Using grid() makes the interface clean, aligned, and easy to adjust.

Buttons and Commands

            calculate_button = Button(frm, text="Calculate MPG", command=calculate_mpg)
            exit_button = Button(frm, text="Exit", command=exit_program)

Buttons connect user actions to program behavior. The command parameter specifies which function runs when the button is clicked.

This is the key connection between the GUI and the event-driven logic.

The Main Event Loop

            frm.mainloop()

This line starts the event loop.

  • The window appears on the screen
  • The program waits for user actions
  • Button clicks trigger their assigned functions

Without mainloop(), the window would open and immediately close.

Why This Design Matters

This program demonstrates important software development concepts:

  • Separation of logic and interface
  • Readable, modular code
  • Event-driven thinking
  • User-friendly interaction

These concepts scale directly to professional desktop applications, web applications, and mobile apps.
