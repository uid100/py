Estimating Pi with Monte Carlo Simulation

This program demonstrates event-driven programming, random sampling, and data visualization using Python and matplotlib. Instead of calculating π using a formula, we estimate it by randomly sampling points and visualizing the results.

The program responds dynamically when the user selects different sample sizes using GUI controls. This makes it both interactive and visual.

What Is the Monte Carlo Method?

The Monte Carlo method uses random sampling to estimate numerical values. For estimating π:

  • Imagine a unit square (1 × 1)
  • Inside the square, place a quarter circle of radius 1
  • Randomly generate points inside the square
  • Count how many points fall inside the quarter circle

Since the area of the quarter circle is π × r² / 4 and the area of the square is 1, the ratio of inside points to total points approaches: 

π ≈ 4 × (inside points / total points)

As the number of samples increases, the estimate becomes more accurate.

Estimating π with the Monte Carlo Method

This program demonstrates an event‑driven scientific visualization using Python, matplotlib, and the Monte Carlo method. Instead of computing π directly with a formula, we estimate it by repeatedly sampling random points and visualizing the results.

The program displays a scatter plot that updates dynamically when the user selects a different number of random samples.

Why This Is Event‑Driven

This program is event‑driven because the main computation does not run in a fixed loop. Instead, it responds to user interaction.

  • The program first draws a plot
  • The user selects a sample size using radio buttons
  • An event is triggered when the selection changes
  • A callback function reruns the simulation and updates the plot

This mirrors how real scientific tools and dashboards behave.

The Monte Carlo Method

The Monte Carlo method uses random sampling to solve problems that may be difficult or expensive to calculate directly.

To estimate π:

  • Imagine a 1×1 square
  • Inside it, place a quarter‑circle of radius 1
  • Randomly generate points inside the square
  • Count how many land inside the circle

Since the area of the quarter‑circle is π / 4, the ratio of points inside the circle approximates that same value.

Generating Random Points

The get_points function generates random coordinates using Python’s random.random() function. 

x = random.random()
y = random.random()

Each point is tested using the equation: 

x² + y² ≤ 1

Points that satisfy this condition lie inside the quarter‑circle. Others are classified as outside.

Plotting and Visualization

The draw_plot function handles both computation and visualization.

  • Clears the axes
  • Generates random points
  • Calculates the estimate of π
  • Displays inside vs. outside points
  • Updates the plot title with the estimate and error

This tight feedback loop helps students visually understand why more samples lead to greater accuracy.

Measuring Error

The program compares the estimate with Python’s built‑in value of π from the math module. 

error = |estimate − actual| / actual × 100

Displaying percentage error reinforces numerical accuracy and convergence concepts.

User Interaction with Radio Buttons

Matplotlib’s RadioButtons widget allows the user to select different sample sizes.

When the selection changes, this line connects the event to the handler: 

radio.on_clicked(lambda label: draw_plot(fig, ax, int(label)))

This is a direct example of event‑driven programming: the visualization responds immediately to user input.

Program Execution Flow

  1. Create the figure and axes
  2. Draw the initial plot
  3. Register radio button event handlers
  4. Start Matplotlib’s event loop with plt.show()

Once plt.show() is called, Matplotlib takes over and waits for user interaction.

Installing Required Libraries

This program requires Python and the Matplotlib library.

Most systems already include the random and math modules. If Matplotlib is not installed, use: 

pip install matplotlib

On some systems, you may need: 

python -m pip install matplotlib

After installation, restart your IDE to ensure the library is recognized.
