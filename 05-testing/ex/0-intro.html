Software Testing

This lab provides an opportunity to apply the concepts and principles presented in the module and chapter 5 of the text.

When you are writing code, you will likely encounter errors in three different stages of development.

  1. Syntax Errors or compile-time errors - your code will not compile and run until these are resolved.
  2. Runtime Errors - also known as exceptions, these issues may be handled in code for a better user experience, but should still be resolved.
  3. Logic Errors - sometimes more difficult to identify, the code may run and produce incorrect results
