Exercise 4

2023 MLB Post-season

Description

After the Major League Baseball regular season, the teams with the best records match up to determine division, and league championships, and the final two teams play in the World Series.

Dowload the data file linked below with the 2023 post-season game results, and write a program to

  • Read the CSV file
  • Create parallel arrays to track and contain
    • Names of the teams in the post-season
    • Total runs for those teams
    • Number of games won
  • Display to the screen
    • which team scored the most (cumulative) runs in the post-season and how many (total))
    • which team scored the least number of (cumulative) runs in the post-season and how many (total)
    • which team won the most number of games in post-season, how many
    • which team won the least number of games in post-season, how many
  • Use exception handling when you open the file for reading
