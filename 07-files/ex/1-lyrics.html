Exercise 1

Parse and count strings with File I/O

Description

Start this exercise with the code as written. Enter the code as it is presented to demonstrate the fundamentals of reading and writing-- to and from text files.

After it is tested,

  • Add exception handling to validate the user inputs an integer at the file selection menu.
  • Add exception handling to handle a FileNotFoundError if the code tries to open a file which does not exist.

 

This lab will build on skills that you have already practiced in previous labs, including handling lists, tuples, function calls, and reading and writing data to the console.

Just for fun, we'll read some song lyrics to find the most used words in a few different songs.

Analyzing Music Lyrics

Steps:

  1. In this exercise, you are given some text files. Download them and move them to your lab folder. We will use simple song lyrics because they are readily available in text format without a lot of extra typing.
  2. In the demo code,
    1. Display a list of available text files
    2. Get the user's selection
    3. Open and read the text file and parse the strings into a Python list
    4. Loop through the list and each time a new string is found, add it to the list, or increase a counter if it is already on the list.
    5. Identify the most commonly used string, based on the highest occurrence count
    6. Display the results to the console
    7. Write the results to a new list and add the data to a .csv file
