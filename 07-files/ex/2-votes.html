Exercise 2

Votes!

Description

For this exercise, the class has voted for a new Official Chief Handshake Dissemination Officer (classroom greeter) and the results are in a text file.

Your objective: write a program ("vote_counter.py") to count the results.

  1. read the voting results from a text file,
  2. assemble the list of each of the names from the voting file (this will be a short list),
  3. count how many votes each person received
  4. and print the total vote count for each of the named candidates
  5. optional: calculate who received the most votes and announce the winner

 

To keep it interesting, instead of downloading the voting results, use this code to build the voting list. The output of this file will be the input for your program.

Note. This code is meant to generate test data. It includes values hard-coded for testing (names, random-seed). These may change for additional testing.

Name this file votes.py

Hint: you can use this code to read the file:

    with open("votes.txt", "r") as f:
        votes = f.read().splitlines()

 

Do not hard-code values in your solution. There may be any number of names and votes (lines) in the data file. The example data input is just one possibility. Use find_string() from your Methods module as you did in Ex.1 to build a list of distinct names and counts.

Don't forget to include your name in the header comment block

Reminder

Include both votes.py and vote_counter.py in your (zipped) lab folder.
