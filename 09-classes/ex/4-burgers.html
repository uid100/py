Ex. 4: Burgers

Exercise 4

class Burger

This exercise is very similar to the first exercise and the pizza demo.

Create a custom class called Burger that will have the following properties: Customer name, order No., burger type, quantity ordered and price. You will implement get() and set() methods for these along with a constructor.

  1. Complete a class model in draw.io. Export the image to jpg and name it Burger_ClassModel.jpg.
    No points will be given for .drawio (XML) files. These must be exported as jpg!
  2. Create a new Python file and class called Burger. Review the steps and code in the previous exercises, if needed.
  3. Implement an appropriate constructor, getter methods and setter methods.
  4. Price is computed based on the type of burger ordered and then multipled by the quantity ordered. There is no sales tax. Burger types and prices are in the table below. There is room to be creative if you want to use some favorites of your own.
    burger menu
    Burger Type Price
    Regular $1.75 each
    Cheese $2.00 each
    Double meat $3.50 each
    Double meat, bacon & cheddar $4.50 each
  5. Store the prices as static data in the class, recommend using parallel arrays (lists) to store the burger types and prices.
  6. The order No. should be a unique number that is automatically generated by a class method using a static variable for each new order.
  7. The price and order number are not passed in as parameters to the constructor. They are computed and assigned by the class.
  8. Implement a public method called to_string() that will return a string containing customer name, order No., type, qty, and total price.
  9. Create a new Python code file called BurgerTest.py. It must prompt for customer name, order No., burger type, and quantity ordered.
  10. Test your application. Make sure it calculates properly for each burger type. Test with quantities greater than 1 to make sure the extended price (price * qty) is calculating properly.

Be sure to review the rubric before you submit your project to make sure you haven't missed anything.
