Ex. 1: Class Magazine

Magazine Subscription Class

This first exercise will be for a magazine subscription class. To keep things quick and simple, there are just a few properties given in the exercise. In a real world application, there would probably be quite a few more. When designing user-defined classes, UML class models are used to define the class. We'll create these using Draw.io. We'll cover the Unified Modeling Language (UML) in more detail later.

Class models are a common software design tool used by software developers to design and document amd communicatethe structure of a class. They are not flowcharts. They are not meant to show the flow of logic in an application. They are meant to show the structure of a class. They are meant to be a "cheat sheet" for coding the class in a programming language. They are an important communication tool between software developers and other stakeholders in the software development process.

Creating the Class Model

The Class model is a software component design diagram that is one of the diagrams in the Unified Modeling Language (UML) standard.

The Class model is not a flowchart.

Draw.io is an online diagramming tool. As a cloud-based tool, you can access it from any device with an internet connection. Since it is an external tool, some details of the interface may change over time. If you have trouble finding something, ask in our course discussion forum.

Navigate a web browser to draw.io, select Blank Diagram and click the Create button. You can save to a file later.

Scroll down to UML and click the arrow to expand the palette.

Locate Class in the tool palette, drag and drop a class template onto the page.

Notice that a class model is split into 3 compartments (Format matters!). The top compartment is the class name, the middle compartment contains the attributes or properties, and the bottom contains the methods or operations. Click inside each compartment and edit as needed. We’ll shorten the class name to Magazine to save some typing.

For attributes and methods, a minus (-) prefix means that member is private and a plus (+) indicates public. Attributes are normally declared private and methods are normally public unless they are used only in the internal workings of the class.

Optionally, you can specify the data type as shown in the sample Magazine class below.

We'll create a method called toString() that will return a formatted string of the subscriber name, magazine title and months remaining.

The book also shows the getters and setters in the methods compartment. Some software developers omit these in a class model because it's a given they exist and, if there's a large number, they can make a class model very large and unwieldy in a hurry. If you want to add the getter and setter methods in, that's perfectly fine.

You can click on each individual compartment and make larger or smaller as needed.
