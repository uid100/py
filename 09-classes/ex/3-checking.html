Ex. 3: Checking Account

Exercise 3

class CheckingAccount

In this exercise, you will design and build an application that allows the user to enter information for a checking account and then display it.

To do this, you will create a new class called CheckingAccount that will contain properties for the account number, customer name, customer address and account balance.

  • Customer name and address should be set by the user when the account is created using parameters in the constructor.
  • The Account Number should be assigned by the class automatically, using a static, not an instance variable. You can call it "counter."
    Hint: Don't pass this as a parameter to the constructor.
  • The initial balance should be set to $0.00 when the account is created.
    Hint: Don't pass this as a parameter to the constructor. Set it in the constructor body.
  1. Complete a class model in draw.io. Save it as CheckingAccount_ClassModel.jpg
  2. Create a Python code file in your Lab folder called CheckingAccount.py
  3. Code a constructor, getter methods, setter methods, the to_string() method
      Hint:
    • Attributes include: account number, customer name, customer address and account balance
    • The balance property should not have a setter method. It will be initialized (0.0) in the constructor and then updated by the credit() and debit() methods.
    • The account number should be assigned by the class automatically, using a static, not an instance variable. You can call it "counter."
      Hint: Don't pass this as a parameter to the constructor.
    • All of the properties should be coded as private (with double underscores).
  4. Add methods: credit() and debit(). (You may call these deposit() and withdraw() if you prefer.)
  5. The to_string() method must return a formatted string with the values for all the properties above.
  6. Create a new Python code file called CheckingAccountTest.py. This will be the test fixture application.
  7. Your test fixture code will have prompts for customer name and address. Additionally, you must have a prompt to debit an amount and a prompt to credit the account.
  8. We'll use the constructor to set the account_number and set the initial balance to $0.00
  9. Use the to_string() method to display the account information.
  10. Be sure to test your work.
